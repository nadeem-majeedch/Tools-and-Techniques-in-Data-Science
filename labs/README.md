# Labs

Ten hands-on lab exercises, mostly completed during the hands-on block of a
session and finished at home. Each lab maps to a CLO and has a starter notebook.

| Lab | Session | CLO | Topic |
|---|---|---|---|
| `lab-01` | W3 S6 | 1 | NumPy: arrays, operations, aggregation |
| `lab-02` | W5 S10 | 1 | Pandas data cleaning |
| `lab-03` | W6 S12 | 1 | Data acquisition & combining datasets |
| `lab-04` | W7 S14 | 1 | Visualization with Matplotlib & Seaborn |
| `lab-05` | W9 S18 | 2 | Linear regression & evaluation |
| `lab-06` | W10 S20 | 2 | Classification (k-NN, logistic regression, decision trees) |
| `lab-07` | W11 S22 | 2 | Clustering & pipelines |
| `lab-08` | W13 S26 | 3 | PandasAI natural-language queries |
| `lab-09` | W14 S27 | 3 | Ollama local models |
| `lab-10` | W15 S30 | 3 | n8n automation + ethics reflection |

## Conventions

- Each lab folder: `lab-0X-README.md` (objectives, tasks, checkpoint questions)
  and `lab-0X-starter.ipynb`.
- Graded: notebook correctness, code quality, checkpoint answers (see
  `../assessment-plan.md`).
- Submitted via Git before the start of the next session.

*Work in progress:* starter notebooks will be added alongside each lab.
