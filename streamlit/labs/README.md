# Streamlit Labs — Practical Exercises

Four progressive labs, one per stage of the module. Students write the code
themselves; each lab gives the problem, task list, starter hints, expected
output, and a challenge. Complete solutions live in `solutions/` (instructor
use).

| Lab | Topic | Skills | Based on |
|---|---|---|---|
| 1 | First App + Widgets | text elements, button, checkbox, selectbox, session state | Examples 1–2 |
| 2 | CSV Data Viewer | file upload, dataframe, metrics, column filters | Example 3 |
| 3 | Interactive EDA Dashboard | charts, matplotlib/seaborn, interactive filters | Example 4 |
| 4 | ML Prediction App | caching, model training, predictions, confidence | Example 5 |

## Grading (per lab, 10 marks)

| Part | Marks |
|---|---|
| App runs without errors (`streamlit run`) | 2 |
| Required widgets + interactions present and working | 4 |
| Correct data logic (filtering / training / prediction) | 2 |
| Challenge completed + code is your own and explainable | 2 |

Students must be able to explain every line in the viva-style check;
AI-generated code they cannot explain scores 0 on the last row.

## Submission

- One `.py` file per lab (or a folder with the app + screenshots).
- Run it in front of the instructor/lab assistant, or submit a short
  recording/screenshots showing each required interaction.
