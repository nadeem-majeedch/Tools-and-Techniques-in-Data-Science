# Final Project

End-to-end data science project in teams of 2–3, integrating all three CLOs.
The complete framework lives in `final-project/`.

## Framework contents

| File | What it is |
|---|---|
| `guidelines.md` | Project rules, timeline, team/scope limits, deliverables checklist |
| `proposal-template.md` | One-page proposal (due W13 S26) |
| `technical-requirements.md` | Environment, allowed tools, dataset rules, repo layout |
| `readme-template.md` | README template for the project repository |
| `report-template.md` | Final report + ethics/reproducibility reflection structure |
| `presentation-template.md` | 6-minute presentation + demo/Q&A prep |
| `viva-questions.md` | Viva question bank (with expected-answer pointers) |
| `grading-rubric.md` | Full rubric (weights from `../assessment-plan.md`) |
| `clo-mapping.md` | Every component mapped to CLOs and Bloom's levels |
| `peer-evaluation-form.md` | Team contribution + peer presentation feedback forms |

## Required components (summary)

1. Problem definition → 2. Dataset/data source → 3. Data acquisition →
4. Data cleaning → 5. EDA → 6. Visualization → 7. Basic ML model →
8. Model evaluation → 9. Interactive Streamlit application →
10. GitHub repository → 11. README → 12. Final report → 13. Presentation

Optional (at least one is recommended for CLO-3, none required): PandasAI,
Ollama, LLM-assisted analysis, AI agent, n8n automation.
