# Assignments

Three graded, individual assignments. Each assignment folder contains a brief
(`README.md`), starter materials, and a rubric.

| Assignment | Released | Due | CLO | Focus |
|---|---|---|---|---|
| `assignment-01` | W6 S12 | W8 S15 | CLO-1 | Acquire, clean, reshape, and analyze a dataset with Pandas |
| `assignment-02` | W12 S23 | W13 S25 | CLO-2 | Train/evaluate regression + classification models; justify choices |
| `assignment-03` | W14 S28 | W15 S30 | CLO-3 | AI-assisted workflow (PandasAI/Ollama) and/or n8n automation + ethics reflection |

## Conventions

- Each brief states: objectives, dataset (see `../datasets/`), tasks, deliverables,
  submission instructions (private GitHub repo), and the rubric.
- Notebooks must be executed and saved with visible outputs; code must run from a
  clean environment (`pip install -r ../requirements.txt`).
- Students disclose AI assistance per the AI-use policy in
  `../assessment-plan.md`.
